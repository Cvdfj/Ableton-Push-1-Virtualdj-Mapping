# Ableton-Push-1-Virtualdj-Sampler-Mapping
This is my custom mapping for the Push 1.

Copy the files to the respective directories of Virtualdj.
Run Virtualdj.

The pads control the sampler, the sampler must be routed to Deck 4 (apply deck effects ON and Show effects ON), so you can enjoy all the effects of the deck 4 on the sampler. Expand Pad Layout to 8 columns.

I recommend to enable the 6 effects on deck 4 and then you can browse it on the Push or on screen. 

Important: Not every deck effect works over the samples!

Note: What i do, i let the deck 4 be the master, i press rec on Deck 4, stop recording, loop it and play the deck 4 (you can also load a blank mp3 and loop it). This way this is the master deck and i can control the pitch of the samples with the Push and scratch over. Samples must be Pitched for this to work.

Only the lit buttons do something. :D

- MAPPING

1.- enc1 - fx1 on deck4

2.- enc2 - fx2 on deck4

3.- enc3 - fx on deck4

4.- enc4 - fx on deck4

5.- enc5 - fx on deck4

6.- enc6 - fx on deck4

7.- enc7 - fx on sampler deck

8.- enc8 - Pitch on deck4

9.- enc9 - sampler volume

10.- shift + enc modifies the second parameter of the respective FX.

11.- play button - stop all slots

12.- record button - locks-unlocks the sampler deck (prevent deletion or saving samples)

13.- delete + pad - stop the sample if playing, delete the sample if its stop.

14.- add_effect button + enc - changens the effect

15.- tap_tempo button - enable touch FX on the encoders.

16.- first row of small pads - enable effects

17.- last first row small pad - all fx off (yellow)

18.- second row of small pads - select what effect is controlled by the touchd trip.

19.- Last second row of pads - touch effect with the touch strip (red).

20.- small arrow buttons - change bank

21.- curson buttons - focus deck A or Deck B

22.- encoder (the more to the left) - adjust size of the loop

23.- master button - toggle Master Deck 4 ON/OFF

24.- device button - show/hide sampler panel

25.- shift button + Pad - it opens the sample editor



- SCREEN INFO -> (1 row has 4 grids - 4 rows in total):

  row 1, grid 1-6 - fx 1 to fx6.

  row 1, grid 7 - sampler fx.

  row 1,grid 8 - Master BPM.

  row 2, grid 1-7 - effect param 1.

  row 2, grid 8 - pitch deck 4.

  row 3, grid 1-7 - effect param 2.

  row 3, grid 8 - Sampler Volume.

  row 4, grid 1-2 - Last played sample name.

  row 4, grid 3 - sample bank name.

  row 4, grid 4 - Focus Deck A or B.

  row 4, grid 5 - Pad lock status (lock or arm), Encoders Touch Effect on or off (on shows EFX,  off show nothing).

  row 4, grid 6 - last played sample group.

  row 4, grid 7 - last played sample lenght.

  row 4, grid 8 - las sample bpm.
