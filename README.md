# Ableton-Push-1-Virtualdj-Mapping
This is my custom mapping for the Push 1.

1.- Copy the files to the respective directories of Virtualdj.
2.- Run Virtualdj.

The pads control the sampler (64 full color), the sampler must be routed to Deck 4, so you cna enjoy all the effects of the deck on the sampler.
Only the Lit buttons do something. :D

enc1 - fx1 on deck4
enc2 - fx2 on deck4
enc3 - fx on deck4
enc4 - fx on deck4
enc5 - fx on deck4
enc6 - fx on deck4
enc7 - fx on sampler deck
enc8 - Pitch on deck4
enc9 - sampler volume
shift + enc modifies the second parameter of the respective FX.
play button - stop all slots
record button - locks-unlocks the sampler deck (prevent deletion or saving samples)
delete + pad - stop the sample if playing, delete the sample if its stop.
add_effect button + enc - changens the effect
tap_tempo button - enable touch FX on the encoders.
first row of small pads - enable effects
last first row small pad - all fx off (yellow)
second row of small pads - select what effect is controlled by the touchd trip.
Last second row of pads - touch effect with the touch strip (red).
small arrow buttons - change bank
curson buttons - focus deck A or Deck B

Screen (1 row has 4 grids - 4 rows in total):
row 1, grid 1-6 - fx 1 to fx6
row 1, grid 7 - sampler fx
row 1,grid 8 - Master BPM
row 2, grid 1-7 - effect param 1
row 2, grid 8 - pitch deck 4
row 3, grid 1-7 - effect param 2
row 3, grid 8 - Sampler Volume
row 4, grid 1-2 - Last played sample name
row 4, grid 3 - sample bank name
row 4, grid 4 - Focus Deck A or B
row 4, grid 5 - Pad lock status (lock or arm), Encoders Touch Effect on or off (on shows EFX,  off show nothing)
row 4, grid 6 - last played sample group
row 4, grid 7 - last played sample lenght
row 4, grid 8 - las sample bpm
